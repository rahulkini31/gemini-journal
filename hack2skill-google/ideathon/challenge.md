
Build a Secure "Personal Gemini Journal"

Most AI-generated apps look great in a demo and fall apart in production — hardcoded keys, no auth boundaries, shared databases with zero isolation. Your challenge is to fix that at the source: configure Google AI Studio to think like a security engineer, then build an authenticated web app where users sign in, journal or brainstorm with Gemini, and have their conversations saved to their own isolated storage.

## What it has to include (Mandatory):

- User authentication: Sign-in via Firebase

- Multi-turn AI interaction: Real conversations with the Gemini API

- Isolated data storage: Each user's logs in Cloud Firestore, zero cross-user leakage

- Secure key management: API keys via Google Cloud Secret Manager, never hardcoded

- Plus at least one original feature enhancement of your own that goes beyond the base spec.

The Challenge

Most AI-generated apps look great in a demo and fall apart in production — hardcoded keys, no auth boundaries, shared databases with zero isolation. Your challenge: configure Google AI Studio to think like a security engineer before it writes a single line of code, then use it to ship a real, production-grade application.
You'll set this up as a foundational step, then build the Personal Gemini Journal — an authenticated web app where users sign in, brainstorm or journal with Gemini, and have their conversations automatically summarized and saved.
